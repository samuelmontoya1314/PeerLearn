## 🚀 Cómo usar la Presentación y el MVP en Vivo

1. Abre `index.html` o ingresa al enlace de **GitHub Pages** del repositorio.
2. **Atajos rápidos de teclado:**
   - **`P`**: Ir al **Pitch Deck Ejecutivo** (10 diapositivas interactivas).
   - **`D`**: Ir a la **Demo en Vivo del MVP** (4 vistas funcionales).
   - **`T`**: Alternar entre **Modo Oscuro** y **Modo Claro**.
   - **`N`**: Abrir el **Panel de Notas del Orador**.
   - **`F`**: Pantalla completa.
   - **`←` / `→` / `Espacio`**: Cambiar de diapositiva.
